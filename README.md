# AI Document Forensics

## About The Project
This is an AI-based document tampering detection and forensic verification system. It is designed to analyze documents and detect any unauthorized changes or forgeries using machine learning.

## Project Files
* `train_models.py`: This script is used to train the AI model on document datasets.
* `main.py`: This is the main application script used to run the tampering detection on a given document.

## How to Use
1. Make sure you have Python installed.
2. Install the necessary libraries (like OpenCV, TensorFlow, or scikit-learn).
3. First, run the training script if you need to build the model:
   ```bash
   python train_models.py
